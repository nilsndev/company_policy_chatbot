## Notes on the two reference-enrichment "misses" (priya-03, dana-04)

Inspecting rather than just trusting the 2/4 average (`rag-evaluation` skill): both misses are an artifact of the golden-set question, not a pipeline defect. In both cases the expected related policy was phrased closely enough to the question that the vector search surfaced it directly in the top-k primary results — e.g. dana-04 ("classify sensitive data") pulled `data-classification-policy` in as a *direct* hit at position 1, so it was already in `seen_policy_ids` by the time `_enrich_with_references` ran and correctly declined to add it again. The scoring here only counts a hit when the chunk arrives via the `REFERENCES` enrichment path specifically (`supplementary=True`), so it undercounts: the related content did reach the model's context in both "misses", just via direct recall rather than graph traversal. The two cases that genuinely needed the graph to pull in a policy that direct vector search had *not* already surfaced — marcus-03 (Incident Response → Data Breach Notification) and sam-06 (Onboarding → Code of Conduct/Acceptable Use/Anti-Harassment) — both hit. A future golden-set revision should phrase cross_reference questions to avoid this overlap (ask about the primary policy only, not both topics at once) so the metric isolates the enrichment mechanism cleanly.
